Sprayer & Row

Total GPM = both sides combined, measured with the sprayer running in place.
Double row (both sides/pass)
Single row (one side/pass)
Double row: sprayer hits both sides of the row (or both adjacent rows) in one pass — the standard airblast blueberry setup. Single row: only one side gets sprayed per pass (e.g. wide rows needing two trips), which roughly doubles the water needed per acre at the same speed.

This Tank's Mix

Target rate per acre is the label rate. Target GPA and acres-per-tank are calculated from your actual mix, so the label rate always drives the status colors.
Formula: Actual GPA = (Total GPM × constant) ÷ (Speed × Row spacing). Constant is 495 for double row (both sides sprayed in one pass) or 990 for single row (one side per pass), per standard airblast calibration guides (e.g. Ohio State & UGA Extension). Target GPA is back-calculated from your label rate and your actual tank mix, so the Drive screen's status colors always track the label rate directly. Always confirm calibration with a static catch-test before relying on this for chemical application — GPS speed and sprayer output readings can drift.
